                                        Идея моего проекта:"Платформа для обмена рецептами"
Идеей вдохновения стал русский сериал "Кухня".
Структура проекта(Проект полностью написан мной):
Backend(Django): Управление данными рецептов, пользователей и отзывов.
Frontend(HTML, CSS, JS): Пользовательский интерфейс, взаимодействие с пользователем через формы, динамическое отображение данных.
База данных(SQLite): Хранение рецептов, пользователей, комментариев и т. д.
